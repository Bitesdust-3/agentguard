# Changelog

All notable changes to AgentGuard are documented in this file.

## v1.0.0 - 2026-08-30

- Added an OpenAI-style non-streaming Chat gateway with Mock and OpenAI-compatible providers.
- Added explainable Secret, PII, and Prompt Injection detection with input/output policy enforcement.
- Added configuration-driven Tool Policy, approval workflow, and mock execution.
- Added privacy-minimized, fail-closed SQLite Audit persistence and a local Dashboard.
- Added the reproducible 266-case Curated Benchmark v1 and Benchmark Dashboard.
- Added Docker packaging, Docker Compose, CI, and a fictional-data demo script.
